The weather dataset contains a total of 8784 records having 8 columns (8784 x 8)-
'Date/Time', 'Temp_C', 'Dew Point Temp_C', 'Rel Hum_%', 'Wind Speed_km/h', 'Visibility_km', 'Press_kPa', 'Weather'.

The datatype of each column is as below,
Date/Time -	object
Temp_C	- float64
Dew Point Temp_C -float64
Rel Hum_%	- int64
Wind Speed_km/h - int64
Visibility_km - float64
Press_kPa	- float64
Weather	- object

Pandas libary is used for the analysis.

The main methods used for analysis include - min(), max(), mean(), isnotnull(), isnull(), unique(), nunique(), value_counts(), dtypes(), groupby(), get_group(), sum(), rename()

Techniques used - grouping, filtering
